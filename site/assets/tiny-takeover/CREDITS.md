# Tiny Takeover — genuine Minecraft Java Edition 26.1 panorama

Artwork / game imagery: **Mojang Studios / Microsoft**.
Six original title-screen panorama PNGs, sourced from the **26.1** asset branch of
InventivetalentDev/minecraft-assets, pinned at
`1a751e5f4f158777313d1df6909f63a60c3964bf`:
https://github.com/InventivetalentDev/minecraft-assets/tree/1a751e5f4f158777313d1df6909f63a60c3964bf/assets/minecraft/textures/gui/title/background

This is the actual Java 26.1 Tiny Takeover cubemap, not a fabricated landscape,
not the older Xbox México screenshot, and not an AI-generated substitute.
All six original 1024×1024 PNGs are retained byte-for-byte. The static WebP fallback
is a compressed derivative of face 0, with no generated pixels or upscaling.
Git blob identities, original sizes and SHA-256 values are in `source.json`.
